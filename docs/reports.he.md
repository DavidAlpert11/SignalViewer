# כתיבת דוח

<div dir="rtl" markdown>

מגרסה 1.31 דוח הוא מסמך שכותבים - כמו Markdown - ובתוכו הגרפים, הלשוניות והערכים שלכם.
**דוח** בסרגל הצד פותח אותו במקום הגרפים (אותו כפתור מחזיר); כותבים בצד אחד, הדף שייווצר מוצג בצד השני תוך כדי
הקלדה, ו-**HTML**, ‏**PDF** ו-**Word** שומרים אותו.

- **גרף או לשונית:** `[[יציבות]]` כל הלשונית, `[[יציבות.גלגול]]` גרף אחד, `[[tab2.plot3]]` לפי מיקום.
  אחרי `|`: חלון זמן `10..60`, ‏`all`, ‏`no table`, ‏`table only`. גם `[[notes]]`, ‏`[[findings]]`, ‏`[[investigation]]`, ‏`[[process]]`, ‏`[[verdict]]`.
- **ערך:** `{{ max(Roll) }}`, ‏`{{ mean(Speed, 10, 60) }}`, ‏`{{ rms(Roll - DesRoll, when="משב") }}`,
  ‏`{{ stretches("משב") }}`, ‏`{{ peak = max(Roll) }}` ואז `{{ peak * 2 :.2f }}`. כל ערך מחושב על **כל הדגימות**.
- **כתיבה:** `#` כותרת, `**מודגש**`, `- רשימה`, טבלאות, `> [!FINDING]` תיבת ממצא, `$x^2$` נוסחה, `\newpage` מעבר עמוד.
- אין צורך להקליד: רשימת **הוספה** משמאל (לחיצה או גרירה), **הוסף לדוח** בתפריט ⋯ של גרף, והשלמה אוטומטית אחרי `[[` (Tab).
- מה שלא ניתן למלא (קובץ סגור, גרף שאינו קיים) מסומן ⚠ אדום עם הסיבה - לעולם לא תא ריק או מספר ישן.
- דוח מגרסה קודמת נפתח כמסמך שהטופס שלו יצר - אותם חלקים באותו סדר.

## דוחות מוכנים מחלקים (1.32)

ליד הטקסט האפליקציה מראה מה יש בקבצים הפתוחים - זוגות פקודה / ביצוע, אובייקטים על המפה, מצבים, קבצים להשוואה - ולחיצה
אחת כותבת **דוח אוטומטי** (או סקירת בקרה, סקירת ניווט, השוואת קבצים, סקירת קשר) שבנוי מחלקים, ואותו עורכים כרגיל:

| כותבים | מקבלים |
|---|---|
| `[[overview]]` | סקירת ההקלטה: סיגנלים, משך וקצב, איכות הנתונים, סטטיסטיקות וגרפים ראשונים |
| `[[tracking]]` | פקודה מול ביצוע: שגיאת RMS ומרבית, הטיה, השהיה, overshoot וזמן התייצבות לכל צעד, עובר / נכשל מול טולרנס (`\| tol 2, outside 1%`) |
| `[[navigation]]` | שגיאות מיקום, מהירות וזוויות של כל אובייקט מול הייחוס (שנוחש, וניתן להחליף: `\| ref GPS`) |
| `[[states]]` `[[trajectory]]` `[[moments]]` | התרחיש: כל מצב לאורך הזמן, המסלול על המפה, והרגעים המיוחדים בציר זמן אחד |
| `[[differences]]` | ההבדלים העיקריים בין הקבצים: מדורגים, האזור המרכזי של השינוי והסיגנל הראשון שסטה |
| `[[messages]]` | ההודעות בזרם בתים: המבנה (כותרת, אורך, סוג, checksum), טבלה לכל סוג, הסדר, הפסקות, בקשות ותשובות ולחיצת היד - ראו [מבתים לסיגנלים](messages.md) |
| `[[summary]]` `[[toc]]` | על מה להסתכל (הממצאים החשובים, החמורים קודם) ותוכן עניינים |
| `[[plot Roll, DesRoll \| 10..60]]` | גרף משמות הסיגנלים |

אפשר גם להדביק טבלאות מ-Word או Excel ותמונות, לשמור דוח כ**תבנית דוח שלי**, ולשמור כל קטע נבחר ב**חלקים שלי**.
**ניקוי ← הדוח** מרוקן רק את הדוח (ביטול אחד מחזיר).

## LaTeX - כמו ב-Overleaf, בלי אינטרנט (1.33)

את הדוח אפשר לכתוב ב-**LaTeX**, ואפשר גם לשים LaTeX בתוך דוח Markdown. הכול רץ על המחשב: האפליקציה משתמשת ב-TeX
שמותקן בו - **MiKTeX**, **TeX Live** או **MacTeX**, התקנה אחת ואחר כך בלי אינטרנט (ב-MiKTeX: להתקין מראש את כל החבילות,
או את אלה שבשימוש - ההתקנה "תוך כדי" צריכה אינטרנט). בלי TeX במחשב עדיין יוצא פרויקט LaTeX כ-zip ל-Overleaf.

- **בלוק LaTeX בתוך Markdown**: ` ```latex ` … ` ``` ` - כל מה ש-LaTeX כותב (align, מטריצות, tabular) מצויר ב-TeX
  בתצוגה המקדימה, ב-PDF וב-Word, ונכנס כמו שהוא לייצוא ל-LaTeX. כפתור **TeX** בסרגל מוסיף אחד.
- **כתוב ב- ← LaTeX** (בראש מסך הדוח): הדוח הופך למסמך LaTeX - ה-preamble והחבילות שלך, `\section`, `align`,
  `tabular`, `\includegraphics`. ההפניות של האפליקציה ממשיכות לעבוד: `[[Attitude.Roll]]` הוא איור (הגרף כ-PDF
  וקטורי, כל הנקודות), חלק מוכן (`[[tracking]]`, `[[messages]]`…) - הפרקים והטבלאות שלו, `{{ max(Roll) }}` - המספר.
  **התצוגה המקדימה היא ה-PDF** ש-LaTeX מפיק; שגיאה מראה את **השורה** בטקסט - לחיצה מגיעה אליה.
- **PDF (LaTeX)** - הדוח מוסדר ב-LaTeX של המחשב (XeLaTeX: עברית וכל גופן של המחשב). **LaTeX (.zip)** - `main.tex`,
  הגרפים כ-PDF וקטורי ו-`latexmkrc`; ב-Overleaf: *New project ← Upload project*.

דוח עברי ב-LaTeX משתמש ב-`polyglossia` (עם `bidi`) ובגופן העברי הראשון שיש במחשב; מילים באנגלית בתוך משפט עברי מסומנות
`\textenglish{…}` לבד.
