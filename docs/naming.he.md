# תנו שמות לסיגנלים

Signal Viewer מוצא בהקלטה כמה דברים **לפי שמות הסיגנלים בלבד** ומציע כל אחד בלחיצה אחת: בשורה **נמצא בקובץ**
שבפאנל הקבצים (הקובץ החדש ביותר קודם), בקליק-ימני על הקובץ (*נמצא בקובץ הזה ◂*) ובלוח הפקודות (Ctrl+K, קבוצת
*נמצא*). *למה?* בשורה מציג את הסיגנלים שכל ממצא זיהה.

הקליטו (או ייצאו) את הסיגנלים עם שמות כאלה, והאפליקציה עושה את השאר. אותה טבלה נמצאת באפליקציה:
**עזרה ← תנו שמות לסיגנלים**.

| מה האפליקציה עושה | שמות שהיא מזהה | לדוגמה |
|---|---|---|
| **פקודה ותגובה** - גרף לכל זוג, הפקודה מקווקוות לצד מה שהתקבל; מדדי המעקב בבדיקות; `[[tracking]]` בדוח | אותו שם עם מילת פקודה לפניו או אחריו (אחרי `_` `-` `.` או ב-CamelCase), באותו קובץ: commanded, reference, setpoint, command, desired, demand, target, des, dem, cmd, tgt, ref, set, sp | `ctrl.roll_cmd` / `ctrl.roll`, `DesRoll` / `Roll` |
| **אובייקטים במפה** | קבוצה עם קו רוחב וקו אורך (`lat`, `latitude` / `lon`, `lng`, `long`, `longitude`), עם `alt` ו-`roll` / `pitch` / `yaw` (או קווטרניון) אם יש; או צפון / מזרח / מטה במטרים עם ראשית | `uav.lat`, `uav.lon`, `uav.alt` |
| **שגיאות אמת מול ניווט** - שניהם במפה וחלון *השוואת אובייקטים* נפתח עליהם: שגיאות מיקום, מהירות וזווית עם הסטטיסטיקה; `[[navigation]]` בדוח | שתי קבוצות כאלה של אותה פלטפורמה: אחת בשם של אמת (`truth`, `true`, `6dof`, `physics`, `phys`, `groundtruth`, `sim`, `model`, `plant`, `dyn`), אחת בשם של מערכת ניווט (`nav`, `navigation`, `ins`, `ekf`, `ahrs`, `est`, `kf`, `filter`, `fusion`). אותה פלטפורמה: אותו שם אחרי שמוציאים את המילים האלה (`uav1.truth` / `uav1.nav`), או אמת אחת בקובץ. הוסיפו `vel.n` / `vel.e` / `vel.d` ו-`att.roll` / `pitch` / `yaw` לשתיהן לשגיאות מהירות וזווית | `6dof.lat` / `ins.lat`, `physics.lat` / `nav.lat` |
| **מצבים כפסים** מעל גרפי הזמן | עמודה של ערכי טקסט (או סיגנל שלערכיו יש שמות) | `mode` = TAKEOFF, CLIMB |
| **חיישנים בכמה עותקים** - גרף לכל שדה עם כל העותקים, כך שעותק שלא מסכים בולט | אותם שדות תחת קבוצה עם מספר: `[0]` / `[1]`, או `1` / `2` כשרוב השדות זהים | `imu[0].ax` / `imu[1].ax` |
| **מפעילים ורוויה** | `u`, `effort`, `actuator`, `motor`, `servo`, `valve`, `throttle`, `pwm`, `duty`, `torque`, `output` | `act.throttle` |
| **עמודות בתים ← הודעות** | עמודות `byte_0` … `byte_N` (הודעה אחת בכל שורה) | `byte_0`, `byte_1` |
| **ריצות רבות כמעטפת** | שלושה קבצים פתוחים או יותר עם אותם שמות סיגנלים | `run_001.csv` … |

## כותרת שמפעילה את כולם

```
time,mode,6dof.lat,6dof.lon,6dof.alt,6dof.att.roll,6dof.att.pitch,6dof.att.yaw,6dof.vel.n,6dof.vel.e,6dof.vel.d,
ins.lat,ins.lon,ins.alt,ins.att.roll,ins.att.pitch,ins.att.yaw,ins.vel.n,ins.vel.e,ins.vel.d,
ctrl.roll_cmd,ctrl.roll,ctrl.alt_cmd,ctrl.alt,ctrl.speed_cmd,ctrl.speed,
imu[0].ax,imu[0].ay,imu[0].az,imu[1].ax,imu[1].ay,imu[1].az,act.servo_elevator,act.throttle
```

הקלטת הדוגמה שנבנתה כך: **עזרה ← דוגמאות ← מה האפליקציה מוצאת בעצמה** (או *לפתוח את הקלטת הדוגמה* בחלון *תנו
שמות לסיגנלים*) - `examples/automations/platform_run.csv`: אמת 6-DOF ומערכת ניווט של אותה פלטפורמה (הניווט נסחף),
שלוש פקודות והתגובות שלהן, שלב הטיסה כעמודת טקסט, מד תאוצה בשני עותקים (השני נסחף אחרי 150 ש׳) ושני מפעילים
(המצערת ברוויה בטיפוס).
