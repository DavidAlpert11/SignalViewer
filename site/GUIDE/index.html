    Signal Viewer – user guide¶

    Signal Viewer is a workbench for analysing and validating any time-series data – flight, vehicle and bench tests, simulation output, ROS 2 and CAN recordings – as plots you can zoom, measure, check and compare. Everything runs on your computer; nothing is sent anywhere.

    1. Start¶

    • Windows: install SignalViewer-Setup-X.Y.Z.exe (for you only, no administrator rights), or extract the portable .zip and double-click Signal Viewer.bat.
    • Linux / macOS: extract the -portable.7z and run SignalViewer/SignalViewer.
    • The first screen offers examples (a drone flight, the same mission flown twice, three car runs, an ArduPilot log, a pump on a test bench…). One click opens one ready to look at – the quickest way to learn the app.

    2. Open your files¶

    • + Open files in the file list (Ctrl+O), or drop files on the window. CSV and text tables, MATLAB .mat, ArduPilot .bin, PX4 .ulg, MAVLink .tlog, ROS 2 .mcap, HDF5 and Parquet are read directly.
    • From Windows Explorer: right-click a file → Open with → Signal Viewer. If the app is already open, the file opens in it.
    • Ctrl+P (recent and favourites) lists the files and folders you used lately.
    • Beside each file: the time the version on screen was saved. When another program saves the file again, the time turns amber - click it (or press F5, which refreshes every open file) to read it.
    • A CSV with an unusual layout: tick Show import options before opening in the open dialog to choose the delimiter, the time column and the header row, with a live preview.
    • The time axis of an open file (right-click the file → Time axis…): another column as its time (CSV, MAT, Parquet), its unit (ms → s, s → min… or any scale), and its offset. The dialog says first what changes: a column that goes up and down, repeated or missing values, new signals computed against time (derivative, integral, filters), plots that show the column. One Undo puts it all back.

    Each file gets a colour and a short tag (A, B, C…). Signals of the same name from several files are told apart by them.

    3. The screen¶

    • Top: one row - the work areas as one switch (Recordings - your files and plots, Sweeps - a run envelope's results table), then the Recordings tools (open / save, templates, live, undo / redo, clear, Inspector), Ctrl+K, Settings, the theme, the language and Help.
    • Left: the panels – Data (the open files and their signals), Create signals, Compare runs, Investigate, Report and Checks (the verdict, structure and parameters of any file - section 10).
    • Middle: the plots of the current tab. The plot tabs are in the bar above the plots: + makes one, ▾ opens a template or collection - and a template's other tabs: a template may open only its default ones (the ArduPilot full review: Attitude and Flight) and keep the rest there, their number on the ▾. The layout button (1 × 1) splits a tab into rows and columns. When a tab's plots share the time, its flight-mode lane (or any state signal) is a thin coloured band inside the top plot, lined up with its time axis (Settings → Look → Mode band puts it above the plots instead). The timeline shows the same modes as colour along its track.
    • Bottom: the timeline – play, the time shown, the cursor. Time is written in seconds as recorded, like the axes; Settings (the gear, Ctrl+,) can show a clock from the start instead, and holds the theme and the text size.
    • Right: the Inspector – values at the cursor, statistics, the selected signal's settings.

    4. Plot¶

    • Click a signal in the list to add it to the active plot (the one with the coloured frame), or drag it onto any plot. Drop on a plot's right or bottom edge to make a new plot there.
    • The button next to the plot's title (Time ▾) changes the plot's type: Time, X-Y, 3D (XYZ - any three signals on plain axes), Map, FFT, Spectrogram, Envelope (many runs of one quantity), Video. The Map is the earth with its terrain; its bar has the camera Free · On the object (the object chosen beside it),
    • / − / fit, Relation (the relation box shown or hidden), and its extras (a third object, data, events, measure, its own time). The mouse's position is shown in a corner: latitude, longitude, the ground height there and the distance / bearing from the reference. Where the computer cannot draw 3D (remote desktops, some virtual machines) the Map is drawn flat and says so in one quiet line.
    • Right-click a legend chip for its options: second value axis, show as states, move, remove…
    • Many signals in one plot? The legend moves into a column beside the plot by itself (a row per signal, the values aligned, a filter); the plot's menu ▸ Legend puts it above, beside or hides it. Point at a name to bring its line to the front. Each line shows its value at the cursor (and the change Δ between the two cursors) in a monospaced number with its unit.
    • Statistics of what is on screen: the plot's ⋯ menu ▸ Legend ▸ Statistics of the shown window shows beside each line its lowest, mean and highest value over the time on screen, recomputed as you pan and zoom - fast on signals of tens of millions of samples. The mean is the plain mean of the samples in the window, not weighted by time: where the rate changes, the faster part counts more.
    • Your own groups: select signals, right-click ▸ Group these ▸ New group… and give it a name; / in the name puts a group inside another (Nav/IMU). My groups is at the top of the list.
    • Right-click in the plot for: cursor here, note here, previous zoom, show everything, export the data, save or copy the image, axis limits.
    • Conditions (rail → Investigate): the moments where something holds - Speed > 30, abs(Vz) > 5 and Mode == "AUTO" - in every open file that has those signals. Put both cursors around something odd and press Find similar on the bar above them: the condition is written for you, with the count as you change it. Click a condition's name (or press ] / [) to step through its stretches; the one in focus is shaded, the others are thin strips along the top.
    • The stretches of a condition (click its name): a table of them under the list (sort, click to go there), Together in a new tab - all of them on top of each other from their start, end or peak - and What differs inside: the signals that are most different inside the stretches than outside.
    • What changed first? On the selection bar: every signal of the event's file in the order it left its usual range around the span - candidates, not causes - and the lag between any two of them. Under each, the same signal in the other runs: a change that a run without the problem has too does not explain it alone. On a long log, filter the list or take rows and groups out with ×. Try it all on the example find out what went wrong: the tutorial.
    • Runs × conditions (button under the conditions): every open run against every condition, with what tells the runs apart (a payload, a gain, the number in the file name). The odd run is marked; a click opens it at the stretch. Open a folder of runs… brings in a whole Monte-Carlo set.
    • The run at a glance: the strip above the plots - flags (a frozen or saturated signal, a gap, a glitch) and rows of state signals or conditions (+ adds one; click a row's name to replace, move or remove it). Click a stretch to pick it, Ctrl or Shift+click to add one (same row: or, another row: and); Save as a condition keeps the selection. Double-click zooms; × hides the strip.
    • Findings and the report: give a note a status in the Inspector (open, explained, fault, rejected hypothesis) - it keeps the view it was found in. The Investigate panel keeps the steps you took; tick the ones for the report. Include the investigation in the Report panel puts the findings (with their plots), the rejected hypotheses, the steps, the conditions and how to reproduce it before the plots. Save a template while investigating: it keeps the conditions for the next flight.
    • One into each plot, and the error per axis: select the true X, Y, Z and choose Each in a new plot (▾ beside Plot them); then select the flight computer's X, Y, Z and choose One into each plot - X goes with X by name. ⋯ on any of those plots → Error in every plot with two lines: the errors in a new tab, with RMS, the largest error and when.
    • State lanes (flight mode, gear…): right-click the lane, its chip or the signal in the list to show it on this plot only, on every plot of the tab, or on every time plot of every tab - or remove it. Always as a state makes a signal a lane wherever it is added, in every file.
    • Map and 3D objects: Add object on a Map or 3D plot lists the objects found in the recording - every prefix with a latitude and a longitude under it (phys.lat, nav.att.roll, ins2_lat), classified as truth, navigation or receiver by the words in the prefix. Add all adds them in one step (one Undo); untick a row and Add selected for some. Why? says which signals were taken and by which rule, what is missing and what almost matched (yaw_cmd, a misspelt lattitude). Each object takes its signals from its own prefix only - a GPS's position is never mixed with the navigation's attitude. The Position on the map template adds every object of the file the same way, and when a file with objects opens, a line in the file panel offers them (Add all, Choose…, Why?, × to hide it). Truth is drawn as a line, a navigation solution dashed, a receiver as points (Track changes it).
    • Lines: Settings → New lines sets the width and style (solid, dashed, dotted, dash-dot) of every line added from now on - the lines already drawn keep theirs until Apply to all open plots. A line's own style is in the Inspector; Auto dashes a setpoint beside its measured value by itself. To style many lines at once, right-click a group in the signal list → Style the lines…: one colour (or the palette, a colour each), a width and a style for its lines in this plot, this tab or every tab; a field left on Keep stays as each line has it. Lines picked in the legend with Ctrl+click get the same from the Inspector (Style these lines…). One Undo takes it back.
    • Moving plots: drag a plot by the ⠿ beside its title onto another plot, or Move to… in the plot's menu, or Ctrl+Shift+arrows on the active plot: the two plots change places (Undo puts them back); the sizes of the cells stay. Move to… also lists the other tabs and New tab - the plot goes there as it is (its lines, axes, cursors, a map's objects); dropping it on a tab's name does the same (Ctrl: a copy). Add its lines to… joins a plot's lines to another plot of the same kind (Shift+drop on that plot); the source plot is then removed.
    • One plot at a time: M (or the layout button ▸ One plot at a time) fills the tab with the active plot - for a small screen, or to show one plot to a room. 1 - 9 show the others; M or Esc brings all of them back. The layout itself is not changed.
    • A line that looks flat: adding a small signal to a plot of large ones (a current of 12 A beside 3000 rpm) brings a message with To the right axis and To its own plot. Nothing moves until you choose; it is said once per plot and signal.
    • Hiding an object: the eye before an object's name in the chips above the map hides it (Alt+click: only this one; again: all). It is not drawn and Fit ignores it; its chip stays, struck through, for one click back. In the offline pages a click on the legend does the same.
    • Export the flight (a map's or a 3D view's ⋯ menu ▸ Save / export) has three ways out, all from the same samples:
    • Tacview (.acmi)… - a Tacview ACMI 2.2 file: each object's position (altitude above sea level, by its altitude reference) and attitude as the 3D view draws it, 10 samples a second (fewer for a very long recording - the message says so). Each object gets a model Tacview has a 3D shape for (C172, MQ-9, DJI300, AIM-9M, Zodiac, Pickup by its kind) and its own name as the call sign, so Tacview no longer draws it as its plain triangle. An object with no attitude of its own is written without one.
    • Tacview CSV files (a folder)… - one CSV per object, named as Tacview's CSV import wants (C172 (POS) [Blue].csv). In Tacview: File → Open the first, File → Merge the others (Tacview Standard).
    • Google Earth (.kml)… - a track per object; with real dates in the log Google Earth plays it with its time slider.

    Times that are Unix clock seconds become the file's reference time; otherwise the flight starts at 2000-01-01 00:00 UTC in Tacview. An object with no position in the file (latitude and longitude 0, 0 in every sample - ArduPilot's EAHR without an external AHRS) is left out, and the message names it. The shown places go too: the ACMI file has the points as stationary waypoints, the KML every shape. - Places (the Map's ⋯ → Places…, or Ctrl+K Go to a place…): named points, lines and areas on every Map - the airfield, the range, the ground station. Right-click on the Map → Add a place here…; Add a place… takes a typed position (32.687, 35.39 or 32°41'13"N 35°23'24"E); Mark this spot on an object's chip puts one where it is at the cursor; Import… reads .kml, .kmz, .geojson and .csv (name, lat, lon[, alt]). The panel has two lists: Places of this session (saved with it and its template) and My places (yours, in every session - ★ moves a place there). A click flies the camera there; the search box also takes a position; Save this view keeps the camera by name. The mouse readout says how far the nearest place is, and the relation box can compare the reference with a place. - The Map's camera is Free (move it yourself) or On the object: the camera stays on the object as the replay moves it; drag to turn around it, the wheel (or + / −) goes nearer or further - always towards the object itself, all the way in to sitting on it (its own model is hidden there) and looking where you turned. Every change flies there; a session saved with one of the earlier cameras (From above, Around it, Behind it, Cockpit, Look at) opens Free, or On the object when it followed one. A double-click on an object puts the camera on it (elsewhere: Fit everything, Free); Ctrl+K has Map camera: on … / Free. With the 3D view clicked, the keys: F on the object / Free, arrows look around the object (Free: move over the ground), + / − zoom, 0 fits everything. Display shows the flight display of the object the camera is on (attitude, ground speed, altitude, heading; shown by default while sitting on it - the wheel and drags go through it); a mini-map shows the whole flight while the camera is near an object (a click flies there). When the reference and the compared object are one vehicle (truth and a navigation solution), an error surface between their tracks shows where the solution left the truth (its scale and toggle are in the relation box). On a computer without graphics acceleration the sky, shadows and surfaces stay off. - ▶ Story (the Map's bar, and beside Play in a live HTML page): the flight tells itself - the time runs and stops at each moment that matters, the camera flies to the object, a card says what happened. ◀ ▶ step through the moments, Esc ends it, a click on the card stays there. - Settings → Map and objects (for new things only - a session already open does not change): the icon a new object gets by its class (truth, navigation, receiver, other), the camera of a new Map, Always flat (the light drawing), the relation box and names shown or hidden, the track's width, the model size, m / km or ft / NM, coordinates as decimal degrees, degrees-minutes-seconds or MGRS, the folder of your elevation files, the export rate for Tacview / KML and the Story's length. Reset this group restores them. - Moving the map: drag it (a quick drag glides on), zoom with the wheel or + / − in its corner, Fit everything (or a double-click) shows every track, Follow ▾ keeps an object in the middle - dragging while following moves the map around it, Back to following centres it again. Click the map and the keys work on it: arrows move it, + / − zoom, F follows, 0 fits everything (Shift+←/→ still step the cursor). Settings → Camera following an object: Smooth (default) eases after the object, so a noisy position does not shake the view; Exact stays right on it. Drawn flat, On the object has the N button: the map turns with the object (its heading up) and back north again. A line at the bottom says what the mouse does. - The map's background: the Map button in the corner of every map (2D and 3D) shows each background as a picture of the place on screen - Offline (the default, shipped with the app), the online maps marked ☁ (Satellite, Satellite + roads, the street and topographic maps; greyed out with the reason when Settings → Never use the network is on), Borders (country borders and names over the map, with no internet too) and My maps. Opening the picker downloads nothing. - Add a map… takes a raster MBTiles file (fully offline) or your organisation's tile server (XYZ / TMS, for example on the local network); it is used like any background in 2D, 3D and exports. Never use the network blocks a server on the internet, not one on this PC or a private address. - Keep this area offline… downloads an area's tiles at the zooms you choose before going to the field - the size is estimated first, with progress, Stop, and the kept areas listed with their size and Delete. Only where the map's terms allow it (the ground heights and your own servers); OpenStreetMap, Esri and OpenTopoMap forbid bulk downloads and the dialog says so - places you look at are still kept. - Height profile: Profile in the map's bar shows, under the map, the object's height and the ground under it along the distance, for any recording with positions. The cursor's moment is marked; a click in the profile moves the cursor. Where the ground data is coarse it says so and how to get finer ground (.hgt files, or Keep this area offline…). - Arrows along the path: any two signals that are north and east components - a wind, a velocity, a force - drawn as arrows along an object's track, on the map and in 3D (the object's settings › Arrows along the path). The file's own pair is offered by itself (an ArduPilot log's estimated wind, a CSV's velocity). - The rings - the reference and the compared object: with two objects or more on a map, one is the reference (a solid ring; also called the primary) and one is compared with it (a dashed ring; the secondary) - by default the truth and the first navigation solution. The relation box, the comparisons and the errors are measured from the reference. Point at a ring to read this; the chips above the map carry the same ring marks. Choose them in the box's first line: Reference, Compared with, and ⇄ to swap - the same in the 3D view. Shortcuts: click an object (Shift+click for the compared one), the chip's right-click menu, Q / Shift+Q and X while the map has the focus. The box in the map's corner shows, at the cursor: the range (straight line), the horizontal distance, Δalt, the bearing from the reference, the relative bearing (from its heading, + = right), the closure rate (+ while they close) and the time to the closest approach, the heading difference (0-180°) and the compared object's aspect: the angle at it between its tail and the line to the reference - 0° the reference right behind it, 180° nose to nose, with L / R. - Compare objects… (the Compare… button of the relation box; Ctrl+K ▸ Compare objects…): one dialog for "how does each object differ from the one I trust". Choose the Reference, tick the objects to compare and the quantities - Position, Velocity, Attitude (one that an object does not have is greyed with the reason) - then Values, Errors vs the reference or Both, and the frame: NED / ENU in the reference's local frame at each moment, ECEF, LLA (in metres) or the track frame (along / across its heading). Make opens a tab per quantity: a row per component, the values of every object on the left and each object's error on the right, and a row of horizontal / vertical / 3D error. Every line is named by its object and has the object's colour from the map. The dialog then shows the statistics of each error on the full data - RMS, mean, largest |error|, 95 %, and the time of the largest: click that time and the cursor goes there in every plot and on the map. Copy and Save CSV… take the table out. One click at the top keeps the four earlier actions: Plot over time (the box's values as signals), Error signals (nav_vs_phys.err.*), Differences and Overlay. One Undo takes a comparison back. - Compare with similar… (right-click a signal or a group in the list; Ctrl+K): finds the signals of the same file whose names differ in one part only - nav1.att.roll, nav2.att.roll, truth.att.roll; XKF1[0].Roll, XKF1[1].Roll - and lists them as families. Tick the families, choose the reference member (a truth one is suggested) and Values / Errors / Both; Make opens one tab, a row per family. Angle differences are wrapped (359° − 1° = −2°, not 358°). More matches also offers names one or two letters apart, each with why it matched. The same signal across files is the Compare panel's job. - A map out of the app: a map's menu ▸ Save / export has Save image (PNG) - this view, or fitted to all the tracks - and Save as HTML (opens offline): one file with the map, the tracks, a time slider that moves the objects and their values on hover; it needs no network and no Signal Viewer. Reports (PDF, Word, HTML) now include the tab's maps. - From a script: everything above - finding the objects, comparing them, the statistics, the map and the report - is also a Python call, a command (signalviewer-cli objects | compare-objects | compare-similar | map) and a local REST request, with the same numbers. See Scripting API and Command line in the documentation. - An attitude for a position-only object (Attitude in its row or its form): from motion points it along its course over ground and pitches it by its climb (roll unknown; below Hold the heading below, 1 m/s by default, the heading stays as it was, so a hovering drone does not spin); from
